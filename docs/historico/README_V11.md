# JOCAD 2026 — V11 (Secretaria)

Esta atualização altera o layout da área administrativa, com navegação em Jogos, Medalhas e Boletins. Mantém os identificadores dos formulários e as operações de `admin-online.js`.

## Publicação
Envie todos os arquivos para a raiz do repositório GitHub Pages. Mantenha seu `config.js` existente, com a URL base do projeto Supabase e a chave publicável (nunca use service_role/secret). Não sobrescreva sua configuração já funcional pelo arquivo de exemplo incluído no ZIP.

## Verificações antes do uso oficial
Teste login, salvamento de resultado em ambiente controlado, medalhas, publicação de boletim, saída e visualização pública em outro navegador. Confira as condições RLS de escrita para limitar acesso a staff ativo.
